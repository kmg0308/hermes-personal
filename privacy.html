이 방침은 개인 운영 앱 Hermes Personal과 이 공개 안내 사이트에 적용됩니다. 앱 운영자는 GitHub 사용자 kmg0308이며, 앱은 운영자 본인의 일정 관리를 위해 사용됩니다.

1. 접근하는 정보와 목적

Google Calendar API를 통해 권한이 부여된 캘린더와 일정 정보에 접근합니다. 요청에 따라 캘린더 이름·식별자, 일정 제목·시간·설명·장소, 참석자 등 일정에 포함된 정보가 처리될 수 있습니다. 다른 사람이 만든 공유 일정에도 개인정보가 포함될 수 있으므로 필요한 범위에서만 조회하도록 운영합니다.

현재 OAuth 권한은 https://www.googleapis.com/auth/calendar입니다. 이 권한은 일정 조회뿐 아니라 캘린더 및 일정에 대한 광범위한 관리 권한을 포함합니다. 실제 작업은 사용자가 요청·승인한 일정 관리에 한정합니다. Google 비밀번호를 수집하지 않습니다.

2. 처리 경로와 외부 서비스

앱은 Google Cloud의 개인 서버에서 Hermes Agent를 실행합니다. Google은 계정 인증과 Calendar API 요청을 처리합니다. Telegram을 통해 요청하거나 결과를 받으면 해당 메시지는 Telegram에서 처리됩니다.

요청 해석과 응답 생성을 위해 필요한 메시지 및 캘린더 도구 결과가 설정된 외부 AI 제공자에게 전송될 수 있습니다. 현재 사용하는 제공자는 OpenAI입니다. 따라서 모든 일정 데이터가 서버 내부에서만 처리된다거나 Google 이외의 서비스로 전송되지 않는다고 주장하지 않습니다. 각 제공자의 처리·보존 조건은 해당 서비스의 정책과 계정 설정에 따릅니다.

Google 사용자 데이터는 요청한 개인 일정 기능 제공에 사용합니다. 광고·판매·데이터 중개 또는 범용 AI 모델 학습을 목적으로 사용하지 않습니다. Hermes Personal의 Google API 정보 이용 및 다른 앱으로의 전송은 Google API Services User Data Policy의 Limited Use 요구사항을 따릅니다.

3. 저장과 보안

OAuth 자격 증명과 갱신용 토큰은 앱의 비공개 서버에 저장합니다. 공개 웹사이트나 공개 소스 저장소에 게시하지 않습니다. 대화 기록, 도구 결과, 운영 로그 및 백업에 요청·응답이나 일정 정보가 남을 수 있습니다. 기록·백업을 포함한 모든 데이터의 즉시 자동 삭제 또는 고정된 보존기간을 보장하지 않습니다.

접근 권한을 제한하고 인증 정보를 공개 자료와 분리하여 운영합니다. 개인용 앱이라고 해서 유출 위험이 없거나 절대적인 보안이 보장되는 것은 아닙니다.

4. 연결 해제와 삭제

Google 계정의 서드파티 연결 관리에서 앱 접근 권한을 철회하면 향후 Google API 접근을 중단할 수 있습니다. 권한 철회만으로 이미 저장된 대화·로그·백업까지 자동 삭제되지는 않습니다. 운영자는 비공개 서버의 자격 증명, 관련 대화·로그 및 백업을 별도로 검토하여 삭제해야 하며, Telegram 등 외부 서비스의 기록은 해당 서비스에서 관리합니다.

5. 이 공개 사이트

이 사이트는 GitHub Pages에 호스팅되는 정적 문서입니다. 자체 로그인, 분석 스크립트, 추적 쿠키 또는 데이터 입력 폼을 제공하지 않습니다. 호스팅 제공자인 GitHub는 사이트 제공 및 보안을 위해 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요. 실제 캘린더 정보와 OAuth 자격 증명은 이 사이트에서 제공하지 않습니다.

6. 문의 및 변경

전용 저장소의 문의 게시판으로 문의할 수 있습니다. 공개 게시판에 개인 일정이나 인증 정보를 올리지 마세요. 기능이나 데이터 처리 경로가 변경되면 이 문서를 갱신합니다.
